# DT Enhanced

DT Enhanced is a Chrome Extension that improves the reading experience on DT.no through custom styling and interface enhancements.

## About the Project

I created this project to explore browser extension development and learn how to customize existing websites using CSS and JavaScript.

The goal was to create a cleaner and more user-friendly version of DT.no by adjusting the layout, improving readability, and experimenting with different design improvements.

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript (ES6+)

### Browser Extension
- Chrome Extension API
- Manifest V3
